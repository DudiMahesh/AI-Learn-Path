# AI LearnPath — Setup & Run Guide

## Quick Start (3 Steps)

### Step 1 — Database Setup
```sql
-- Run in pgAdmin or psql connected to your PostgreSQL server

-- Create the database
CREATE DATABASE ailearnpath;

-- Connect to the database, then run:
\i database/schema.sql
\i database/seed.sql
```

Or using the Python script:
```bash
cd database
python init_db.py
```

### Step 2 — Backend Setup
```bash
cd backend

# Create .env file from template
copy .env.example .env
# EDIT .env with your values (see below)

# Create virtual environment
python -m venv venv
venv\Scripts\activate     # Windows

# Install dependencies
pip install -r requirements.txt

# Start Flask server
python app.py
# Server runs at http://localhost:5000
```

### Step 3 — Frontend Setup
```bash
cd frontend

# Install Node dependencies
npm install

# Start dev server
npm run dev
# Opens at http://localhost:5173
```

## Environment Variables (backend/.env)

```env
# === REQUIRED ===
SECRET_KEY=your-random-secret-key-change-this-in-production
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/ailearnpath
JWT_SECRET_KEY=another-random-jwt-secret-change-this

# === AI FEATURES (Optional but recommended) ===
GEMINI_API_KEY=your-google-gemini-api-key

# === OPTIONAL SETTINGS ===
FLASK_ENV=development
FLASK_DEBUG=true
CORS_ORIGINS=http://localhost:5173
EMBEDDING_PROVIDER=sentence_transformer    # or: gemini
LLM_PROVIDER=gemini                        # or: ollama
VECTOR_DB_PATH=./chroma_db
VECTOR_DB_TYPE=chroma
```

**Getting a Gemini API Key (free):**
1. Visit [Google AI Studio](https://aistudio.google.com/)
2. Sign in with Google account
3. Click "Get API Key" → Create API key
4. Copy and paste into `.env` as `GEMINI_API_KEY`

## Training the ML Models

Before the AI features work, you need to train the ML models:

```bash
# From the project root (not backend/)
cd AI-LearnPath

# Activate the backend virtual environment
backend\venv\Scripts\activate

# 1. Generate synthetic training data
python ml/data/synthetic_data_generator.py

# 2. Train Random Forest (skill level prediction)
python ml/train_random_forest.py

# 3. Train K-Means (learning profile clustering)
python ml/train_kmeans.py

# 4. Build TF-IDF recommendation index
python ml/build_recommendation_index.py

# 5. Evaluate models (shows accuracy metrics)
python ml/evaluate_models.py
```

Models are saved to `ml/models/`. The backend loads them automatically.

> **Note:** All training data is **synthetic** (generated by code). Model metrics are estimates on that synthetic data, not real user data.

## Setting Up the RAG Knowledge Base

The AI Learning Assistant needs the knowledge base indexed:

```bash
# From project root, with venv active
python rag/ingest_knowledge_base.py
```

This ingests the sample documents in `rag/knowledge_base/sample_documents/` into ChromaDB.

You can also add more documents through the Admin Panel at `/admin/knowledge-base`.

## Troubleshooting

**Backend won't start:**
- Check `DATABASE_URL` in `.env` is correct
- Ensure PostgreSQL is running and database exists
- Run `python init_db.py` from the `database/` folder

**ML models not working:**
- Run the training scripts in order (see above)
- Check `ml/models/` folder contains `.joblib` files

**RAG Assistant not responding:**
- Set `GEMINI_API_KEY` in `.env`
- Run `rag/ingest_knowledge_base.py` to populate ChromaDB

**Frontend build error:**
```bash
npm install  # Re-install dependencies
npm run build  # Check for errors
```
